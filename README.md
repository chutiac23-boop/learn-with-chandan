# Learn With Chandan — starter website

This is the first responsive front-end version of the Learn With Chandan website.

## Open locally
Open `index.html` in a modern browser, or upload the folder contents to a static hosting service.

## Included
- Mobile-first blue-and-white design
- Uploaded brand logo
- Welcome homepage and navigation
- Classes 9–12
- Mathematics and Science sections
- Materials, announcements, doubts, community, help and about sections
- Responsive mobile navigation
- Search bar preview and notification bell preview

## Important: what is not connected yet
This is a front-end starter, not the complete live platform. Real student registration (mobile/email/Google), cloud-saved progress, teacher accounts, admin controls, upload approval, private doubts, moderated community, quizzes, analytics, push notifications and live search need backend services and configuration. The current buttons clearly indicate features that are not connected yet.

No personal phone number is published in this version. Add a public contact number only when you are ready and have considered using a separate business number.

## Next steps
1. Choose and create a free hosting account/repository with help from a parent or guardian if required.
2. Publish this static version to a free subdomain.
3. Add the database and authentication in a later phase, checking free-tier limits and privacy requirements first.
4. Replace sample sections with your actual lessons, YouTube video IDs, PDFs and announcements.
